# CS5410-001 2024 Project 3 - Lunar Lander

A project I made in 2024 for a game development class. Based on the [1979 Lunar Lander arcade game](https://en.wikipedia.org/wiki/Lunar_Lander_%281979_video_game%29).

Uses super simple Vue for page layout and vanilla JS for the game.

## Install

`npm install`

## Run

`npm start`
